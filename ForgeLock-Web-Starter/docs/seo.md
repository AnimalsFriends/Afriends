# SEO técnico por proyecto

## Antes de generar
Confirmar nombre comercial, dominio final, idioma, descripción, páginas indexables y política de privacidad aplicable.

## Por página
Título único, descripción relevante, encabezados semánticos, canonical absoluto correcto, metadatos sociales, `lang`, imágenes con texto alternativo significativo y enlaces internos válidos.

## Sitemap y robots
Generar `sitemap.xml` solo con URLs canónicas, públicas e indexables. `robots.txt` debe apuntar al sitemap correcto cuando exista dominio confirmado. No declarar `lastmod` inventado.

## Ambientes
No publicar sitemap de producción desde una vista previa. Evitar que entornos de prueba se indexen, usando controles adecuados; `robots.txt` por sí solo no garantiza desindexación.

## Analítica
Google Analytics, Tag Manager o píxeles requieren autorización y configuración de consentimiento cuando corresponda. No inventar IDs.

## Datos estructurados
Solo añadir JSON-LD sustentado en datos reales; probar sintaxis y pertinencia.
