# Accesibilidad práctica

Objetivo: aplicar buenas prácticas alineadas con WCAG 2.2 AA, sin declarar conformidad hasta realizar auditoría suficiente.

- Navegación completa con teclado y foco visible.
- Orden lógico de lectura y encabezados.
- Contraste de texto y controles comprobado.
- Alternativas textuales para imágenes informativas; decorativas con alt vacío.
- Etiquetas de campos, errores claros, instrucciones accesibles.
- Evitar interacciones dependientes solo de hover, color o gestos.
- Respetar preferencias de movimiento reducido.
- Revisar zoom 200 %, tamaños móviles y lectores de pantalla cuando sea posible.

## Validación
Automatización detecta solo una parte de los problemas. Completar revisión manual y documentar hallazgos.
