# Lista de control de entrega

## Contenido y marca
- [ ] Nombre, servicios, precios y contactos verificados.
- [ ] Logos originales, derechos de imágenes y manual de marca respetados.
- [ ] Sin textos de demostración o marcadores `PENDIENTE:` visibles.

## Funcionalidad
- [ ] Navegación y enlaces revisados.
- [ ] Formularios conectados a destino aprobado y probados, o retirados.
- [ ] CTA y WhatsApp probados en dispositivo real.
- [ ] Responsive en móvil, tableta y escritorio.

## Calidad
- [ ] `npm run check` aprobado.
- [ ] SEO y canonical revisados para dominio final.
- [ ] Accesibilidad manual básica completada.
- [ ] Imágenes optimizadas y rendimiento medido cuando sea posible.
- [ ] Política de privacidad/cookies evaluada según tratamiento de datos.

## Seguridad y publicación
- [ ] No hay credenciales en el repositorio.
- [ ] Se verificó que no se afecten otros clientes ni ForgeLock corporativo.
- [ ] Aprobación expresa del responsable registrada.
- [ ] Backup, rollback y destino de despliegue definidos.
- [ ] Publicación ejecutada únicamente tras autorización.
