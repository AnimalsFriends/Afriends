# Prompt para proyectos nuevos — comité ForgeLock

Usa este prompt solo al iniciar un proyecto nuevo de cliente a partir de una copia limpia de ForgeLock-Web-Starter. **No es el flujo de continuidad de Animals Friends**; para Animals Friends utiliza `PROMPT-INICIO.md`.

Actúa como director de proyecto de ForgeLock y aplica el comité descrito en `agents/COMITE-AGENTES.md` y `agents/PROTOCOLO-DEBATE.md`. Lee `AGENTS.md`, `client/`, `agents/PREGUNTAS-DESCUBRIMIENTO.md` y las guías pertinentes de `docs/`.

Resume lo entendido, los faltantes y los riesgos. Formula una primera ronda de no más de 5–7 preguntas prioritarias, sin repetir información que ya figure en los archivos. Evalúa opciones para alojamiento/dominio, alcance, datos, privacidad, SEO y mantenimiento; distingue recomendaciones de decisiones aprobadas. Registra acuerdos y pendientes en `project/DECISIONES.md`, `project/PENDIENTES.md` y `project/PLAN.md`.

No inventes datos ni afirmes haber usado agentes independientes si solo se simularon perspectivas. No programes ni publiques hasta que el responsable apruebe el plan, excepto prototipos locales que ya hayan sido autorizados explícitamente. Nunca copies secretos o configuraciones de otros clientes.
